# civita-validation

Part of CIVITA, the Computational Infrastructure for Validation, Integration, Testing, and Assessment.

Scientific tools and workflows for assessing computational predictions against independent experimental data.

This component is under development. The planned workflows will support systematic assessment of predictive capability and ranges of applicability.

- [CIVITA website](https://civita.network)
- [CIVITA community discussions](https://github.com/civita-network/civita/discussions)
